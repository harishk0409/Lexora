# Lexora — The Living Law Archive

A highly creative, visually distinctive frontend for Legal AI and Research.

## Visual Identity & Features
- **The Living Interactive Wallpaper**: Fullscreen interactive HTML5 canvas simulating an interconnected legal archive with conceptual clusters (Contracts, Criminal Law, Constitution, Property, Torts, Case Law), gravitational cursor physics, shockwaves, traveling pulse signals, and drifting legal citations.
- **Atmospheric Palette**: Deep charcoal foundation (`#0a0b0e`), dark burgundy/crimson accents (`#2a0d14` / `#42121e`), muted antique gold (`#c5a880` / `#d4af37`), and editorial serif typography (Newsreader, Cinzel, Plus Jakarta Sans).
- **Research Portal**: Attuned search experience where background nodes gravitate inward on focus and typing.
- **Cinematic Thinking Sequence**: 4-stage illuminated progression (Exploring the Archive → Connecting Relevant Sources → Assembling Context → Forming Response).
- **3-Column Editorial Workspace**:
  - Left: Library index & legal domain catalog.
  - Center: Judicial assessment with numbered reasoning, interactive citation chips, doctrinal tooltips, and comparative precedent matrices.
  - Right: Evidence panel with circular radial relevance gauges.
- **Document Pull-Out Drawer**: Detailed folio view with highlighted ratio decidendi and bench commentary.
- **Interactive Knowledge Graph**: Topology map tracing Query → Concept → Section → Act → Case → Judgment.

## Getting Started

### Prerequisites
- Node.js 18+
- npm or pnpm or yarn

### Installation
```bash
npm install
```

### Running Development Server
```bash
npm run dev
```
Open `http://localhost:3000` or the port shown in your terminal.

### Building for Production
```bash
npm run build
```
Production assets will be in `dist/`.
